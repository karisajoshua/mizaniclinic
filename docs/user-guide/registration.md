
# Registration Process

This guide walks you through the complete registration process for becoming a Mizani Clinic Ambassador.

## Prerequisites

- Valid email address
- Phone number (Tanzanian mobile number preferred)
- Referral code from an existing ambassador
- Government ID (for verification)

## Step-by-Step Registration

### 1. Access Registration Page

Navigate to the registration page and click "Sign Up" or visit directly:
```
https://your-domain.com/signup
```

### 2. Enter Basic Information

Fill out the registration form with:

- **Full Name**: Your legal name as it appears on your ID
- **Email Address**: Valid email for account notifications
- **Phone Number**: Mobile number for SMS verification
- **Password**: Strong password (minimum 8 characters)
- **Referral Code**: Code provided by your referring ambassador

### 3. Referral Code Format

Referral codes follow the format: `REGION-IDENTIFIER`

Examples:
- `TDSM-AB1234` (Dar es Salaam)
- `ARU-CD5678` (Arusha)
- `MWA-EF9012` (Mwanza)

### 4. Verification Process

After submitting your registration:

1. **Email Verification**: Check your email and click the verification link
2. **Phone Verification**: Enter the SMS code sent to your phone
3. **Profile Completion**: Add additional details and upload ID

### 5. Payment Setup

Configure your payment preferences:

- **Mobile Money**: M-Pesa, Tigo Pesa, or Airtel Money
- **Bank Account**: Local Tanzanian bank details
- **Payment Schedule**: Choose weekly or monthly payouts

## Common Issues

### Invalid Referral Code
- Ensure the code is typed correctly
- Verify the referring ambassador is active
- Contact support if issues persist

### Email Not Received
- Check spam/junk folders
- Ensure email address is correct
- Request new verification email

### Phone Verification Failed
- Verify phone number format (+255...)
- Ensure SMS can be received
- Try alternative verification method

## Next Steps

After successful registration:

1. Complete your ambassador profile
2. Familiarize yourself with the dashboard
3. Generate and share your referral code
4. Start building your ambassador network
