# Registration and receipt activation

1. Open **Register** and enter your name, phone, password, country, region and the ambassador code that referred you. Codes look like `MAP-T1001DSM`.
2. Save the ambassador ID assigned to your account. It is also your referral code and sign-in identifier.
3. Pay the clinic separately using the clinic's current instructions. Staff give you a receipt code recorded in the system.
4. On **Verify your receipt**, enter that code. The database checks it, assigns it to your account and activates your dashboard.

A code cannot activate two accounts. Re-entering your own confirmed code is safe. A missing, invalid or already-used code does not grant access. If verification cannot reach the database, retry when the connection returns.

If you have paid but your receipt is unavailable, contact clinic support. Keep the original receipt. Admin approval cannot bypass receipt verification.
